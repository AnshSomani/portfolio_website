### About This Project
This is a modern, high-performance static portfolio built with:
- **Vanilla HTML/CSS/JS** for absolute maximum performance and control.
- **GSAP (GreenSock)** for smooth scroll-triggered animations and parallax depth.
- **Lenis** for buttery smooth scrolling.
- **Three.js** for interactive WebGL 3D backgrounds.

Feel free to explore the code, but the best way to experience it is by visiting the live site!
